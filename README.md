# 📊 Power BI Finance Dashboard

## Overview

This project is an interactive Finance Dashboard developed using Microsoft Power BI. It provides insights into sales performance, product analysis, customer segments, monthly sales trends, and geographical sales distribution.

## Dashboard Features

- Total Sales KPI
- Total Units Sold KPI
- Product-wise Sales Analysis
- Monthly Sales Trend
- Sales by Customer Segment
- Profit by Segment
- Country-wise Sales Map
- Product Sales Treemap

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Excel Dataset
